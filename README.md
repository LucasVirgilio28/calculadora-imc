# calculadora-imc

Uma calculadora para calcular o seu Índice de Massa Corporal feita com HTML, CSS e JavaScript. Ela permite que o usuário insira seu peso e altura para calcular o IMC e exibe o resultado na tela. 
Observação: Se deve utilizar a vírgula ao digitar a sua altura. Por exemplo: 1,70.

Como usar 

1.Copie este meu repositório:
git clone https://github.com/LucasVirgilio28/calculadora-imc.git

2.Abra o arquivo index.html em seu navegador.

Tecnologias usadas:
-HTML
-CSS
-JavaScript
